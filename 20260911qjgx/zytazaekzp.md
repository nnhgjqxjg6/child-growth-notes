# 汉阳国博方舱医院内的90后男护 ——我院援鄂医疗队员孙权事迹

> 更新时间：2026-09-11 (UTC+8)

**孙权**，一位92年小伙，枣庄市妇幼保健院重症医学科（ICU监护室）男护士，自2014年参加工作以来，一直从事ICU护理工作，能够熟练应用呼吸机、血滤机等生命支持类仪器设备，熟练掌握心电监护、有创动脉压等监护设备的观察，善于气道管理方面的护理工作。新冠疫情发生后，他便积极投入到医院防“疫”一线，并在第一时间写下请战书，主动要求请战湖北。2月9日，随山东省第八批援鄂医疗队奔赴武汉汉阳国博方舱医院支援疫情防控救治，成为在疫区一线奋战大军中的一员，用实际行动践行了一位普通医护人员的使命与担当。“作为一名90后重症监护室护士，有的是活力和劲头，疫情当前，我要去湖北，冲向最危险的地方。”

**八方支援 共抗疫情**

2月9日，作为山东省第八批援医疗队员，他和战友们星夜赶到武汉汉阳驻地。疫情就是命令，次日他们接到指示，与四川、福建、湖北省妇幼共同组建汉阳方舱医院，为了快速投入一线抗击疫情，他们与时间赛跑，除去吃饭休息，其它时间全身心投入到个人防护培训练习中去。孙权被分在护理二组第二分队，为了达到同质化的防护水平，他主动帮助队伍中有短板的战友，把握每一个细节，保证每个队友都能得到最有效的防护。2月11日，方舱医院正式收治患者。队友们分批次进入方舱，作为2组队员，组织上安排第二批入舱，由于时间充分，孙权自发地组织2组人员为战友送行，激发了各位组员团结一心、携手并进、共抗疫情的决心和信心。

**主动担责 攻坚克难**

2月14日，孙权正式入舱，出发前，他将各组汇总的经验心得一一整理与大家共享。入舱工作前首先要做好的就是穿防护装备，队员之间互相检查，不落下一个人，不放过一个点。“大家相互鼓劲，彼此监督防护有没有做好，很团结，很温暖。”到达指定地点后，他们迅速与上一班进行交接。舱内患者整体“症轻量大”，为了尽快熟悉患者的情况，了解所分管病人的需求，孙权带上笔记本到床旁逐一探问，对于患者们提出的要求，他都详细地记录下来。被防护服裹得严实，孙权时常感到呼吸不畅、干渴难耐，但他坚持跟每个患者充分沟通，尽最大努力为患者排解忧愁，让其放松心情，调整心态。他的一名战友，由于经验不足，出现了疑似暴露风险，为了保证战友的安全，他主动承担起两个人的医疗任务，在主任的安排下让队友提前出舱处置。一百多名患者，一个人很难顾全，他汲取前几队的工作经验，主动邀请各单元的单元长、党员组成临时志愿者团队，邀请公安人员一同为大家分发药品、食品，并做好详细记录，确保物尽所需，井然有序。

事后他把这些工作经验总结后传达给队员，为接下来的工作提供了极大便利。临近交接时，方舱指挥部要求整理所有在舱人员信息，他主动承担起信息校对录入任务。时间紧任务重，临近交接，他告知队友不要等他，工作不完成，他绝不出舱。在全员动员下400多名患者的所有信息在交接前顺利采集完成，为了工作能够高效延续下去，他主动将个人联络方式留在舱内，实现舱内与舱外建立起了动态联络机制。回到驻地，他时刻关注舱内动向，第一时间向领导汇报，主动担负起患者信息录入工作，第一次尝试性将舱内信息工作转移至舱外，内外联动，尽可能减少舱内的工作量。此后每天患者的信息收集工作他都时刻关注，直到患者信息采集工作收集完成。

**听从指挥 落实任务**

2月21日，汉阳国博方舱医院信息化系统上线，他同许芳芳老师受护理部兰素萍主任的委托，负责舱内信息化上线的培训和患者信息电子化采集校对工作。他们利用6个小时的时间，对舱内工作人员进行实地培训，对患者信息进行核对和完善，2月21日，所有患者的基本信息登记校对完毕。患者信息采集校对完成后，由于各个班次对移动终端的操作不熟练，不能及时将新入、出院和转院患者进行录入和转归处理，导致移动手机端患者数量与实际数量不一致。为此，他和队友对操作不熟练的队员进行一对一指导，并告知错误问题所在。2月25日，上午9时30分召开第四次党支部委员会，经集体决议，孙权正式加入信息组成为专职成员，属行政组统一管理。同日，舱内实际在院患者数量与移动终端患者数量首次达到一致。

**火线入党 坚定信念**

作为一名90后，孙权时刻以一名党员的的身份要求自己，在湖北他怀着无比激动的心情写下火线入党申请书，主动在这场战疫中接受党组织考验，他表示他将不负所托，尽其所能，冲锋在前，不计生死，以实际行动向身边的共产党员学习，让青春在党和人民最需要的地方绽放绚丽之花。

**内外协调 高效有序**

信息组正式成立后，他主要协助许芳芳组长进行所有信息的整合，以及核酸检测、CT检测、次日出院名单拟定，除此之外，他们还负责对400余名患者的检测结果进行筛查，并将完善的病人信息进行上报。核酸和CT检查的次数越多，他们的筛查条件选择就越复杂，为了保证每位患者都能及时复查，孙权每天都需要全神贯注的去校对每一条信息，不能有丝毫马虎和差错。工作完成后将名单发回舱内，较大地减少了舱内医务人员筛查的难度。此外，他们还需把每日得到CT及核酸检测结果及时更新录入，每日上报在院患者数量、转出及开展病例检测次数、双阳性患者筛查等即时任务。

每天都会有一批又一批的达标患者，每一个名单，每一个报告，都关系到一个活生生的个体，甚至一个家庭，一个社区，一点马虎不得，孙权勇担责任，及时精确地完成了所有工作任务。信息组成立以来，大部分的信息录入工作转移到舱外，有效减轻了舱内人员的信息录入量，极大提高了数据传输的速度和准确性，日常任务完成速度比信息组成立之前效率提升3倍以上。自2月23日至3月8日16时30分，孙权及队友共拟定CT名单562人次，确定实作CT436人次，共拟定核酸检测675人次，确定核酸检测信息583人次，统计出院加转院379人。

**牢记使命 勇往直前**

一个多月的支援工作，充实而富有挑战，“作为一名预备党员，能在人民危难之时肩负起时代的使命，是我这一辈的荣幸”。方舱任务即将结束之际，队里开始选拔相关专业人员组成预备队随时支援其他定点救治机构。作为一名ICU护士，孙权义不容辞地顶上去，再次请战，成为预备二组的一员。疫情仍在继续，坚守仍在继续，援鄂的工作经历，让他更加坚定了誓与疫情抗争到底的信念，作为一名90后医务工作者，他勇于担当，不怕艰辛，积极投身抗击疫情的最前线，奉献自己的一份力量，以实际行动践行着一名共产党员的初心和使命，兑现了自己“站得出来、冲得上去、迎难而上、勇挑重担”的诺言。
